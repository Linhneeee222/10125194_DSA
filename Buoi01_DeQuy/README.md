## Kết quả chạy
```
=== Bài 1: Tính tổng S(n) = 1 + 2 + ... + n ===
Với n = 5: Tổng của 5 số đầu tiên là: 15
Với n = 10: Tổng của 10 số đầu tiên là: 55

=== Bài 2: Tính tổng bình phương S(n) = 1^2 + 2^2 + ... + n^2 ===
Với n = 3: Tổng bình phương của 3 số đầu tiên là: 14
Với n = 10: Tổng bình phương của 10 số đầu tiên là: 385

=== Bài 3: Tính tổng nghịch đảo S(n) = 1 + 1/2 + ... + 1/n ===
Với n = 4: Tổng 1 trên các số của 4 số đầu tiên là: 2.0833
Với n = 10: Tổng 1 trên các số của 10 số đầu tiên là: 2.9290

=== Bài 4: Tính lũy thừa S(x, n) = x^n ===
Với x = 2, n = 10: Kết quả 2^10 là: 1024
Với x = 5, n = 0: Kết quả 5^0 là: 1
Với x = 2, n = -3: Kết quả 2^-3 là: 0.125

=== Bài 5: Tìm ước số lẻ lớn nhất của n ===
Với n = 100: Ước số lẻ lớn nhất của 100 là: 25
Với n = 48: Ước số lẻ lớn nhất của 48 là: 3
Với n = 7: Ước số lẻ lớn nhất của 7 là: 7

=== Bài 6: Tìm ước chung lớn nhất UCLN(a, b) ===
UCLN(48, 18) = 6
UCLN(17, 5) = 1

=== Bài 7: Đếm số chữ số của số nguyên n ===
Với n = 7: Số chữ số của 7 là: 1
Với n = 12345: Số chữ số của 12345 là: 5
Với n = -987654: Số chữ số của -987654 là: 6

=== Bài 8: Tính S(n) = sqrt(1 + sqrt(2 + ... + sqrt(n))) ===
Với n = 3: Kết quả là: 1.712265
Với n = 5: Kết quả là: 1.756238
Với n = 10: Kết quả là: 1.757933
```
